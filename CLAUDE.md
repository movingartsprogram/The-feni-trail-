# The Feni Trail (original page)

"The Feni Trail — One Night. Two Days. Twenty Seats.": the original page for the
Feni Trail experience. One night on a working feni plantation in South Goa, one day
along the coast. Twenty seats, ₹20,000 a head or ₹30,000 for two travelling together.
A MAP Exclusive. Served by GitHub Pages from `main`. This repo is public, so never
put private guest details in it.

## Ground rules

- The owner chose to leave this page as it is. Only change it when explicitly asked.
- `index.html` on `main` is the latest version. If someone uploads an `index.html`,
  it may be older: compare it with `main` and merge changes in. Never replace the
  repo's file with the upload.
- Do not bring back anything listed under "Decided and done" below.
- One page, no build step.

## Decided and done (do not undo)

- Pricing: ₹20,000 per person, ₹30,000 for two travelling together.
- Sections: Into the orchards → Down to the coast → What's included → Questions →
